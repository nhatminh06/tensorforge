# Validation summary

TensorForge Core validation is entirely **analytical**: independently
hand-derived known-value checks, closed-form invariant cross-checks, and
scaling-law tests. There is no silicon validation and no comparison
against measured hardware runs (see `docs/limitations.md`).

Run the full suite:

```bash
pytest -q
```

Current result: **223 passed** (0 failed, 0 skipped) across 12 test
files (`test_gemm.py`, `test_roofline.py`, `test_pe_array.py`,
`test_memory.py`, `test_tiling.py`, `test_schedules.py`, `test_timing.py`,
`test_explore.py`, `test_transformer.py`, `test_convolution.py`,
`test_presets.py`, `test_experiments.py`, plus the Milestone-10
cross-check suite `test_validation.py`).

## Known-value checks

- GEMM: `M=2,N=3,K=4,FP32` -> MACs=24, FLOPs=48, A=32B, B=48B, C=24B,
  ideal DRAM=104B, AI=48/104 (`test_gemm.py`, `test_roofline.py`).
- PE array: `M=17,N=17,K=8` on a 16x16 array -> waves=4, spatial
  utilization=289/1024 (`test_pe_array.py`).
- Tiling/schedules: `M=N=K=4,FP32`, tile `2x2x2`, SRAM=64B -> c-resident
  320B, a-resident 384B, b-resident 384B, all independently hand-derived
  (`test_tiling.py`, `test_schedules.py`).
- Transformer: `B=1,S=2,D=4,H=2,F=8` -> 576 modeled GEMM FLOPs, exact
  operation shapes and repetitions (`test_transformer.py`).
- Convolution: 1x1 conv -> expansion ratio exactly 1.0; 3x3 conv (Cin=3,
  H=W=5, no padding) -> M=9,N=4,K=27, expansion ratio exactly 3.24
  (`test_convolution.py`).

## Independent invariant cross-checks (Milestone 10, `test_validation.py`)

Added specifically to close gaps not already exercised by the per-module
suites above:

- GEMM MAC/FLOP/byte formulas hold across 5 additional deterministic
  shapes (not just the single known-value case).
- 1x1 PE array: `compute_cycles == macs` exactly, across 4 shapes.
- Perfect-fit PE mapping: `compute_cycles * pe_count == macs` exactly
  (no idle PE-cycles) when M/N divide evenly by rows/cols, across 3
  shape/PE combinations.
- All three schedules produce `total_dram_bytes >= gemm.dram_bytes`
  (traffic_amplification >= 1.0) across 3 shape/tile combinations.
- **New**: for a perfectly square GEMM and square tile, a-resident and
  b-resident produce *exactly symmetric* traffic (swapping A/B's roles
  changes nothing when A and B are themselves symmetric) -- this
  complements the existing asymmetric-workload divergence test.
- **New**: Conv2D im2col expansion ratio equals exactly `kernel_height *
  kernel_width` when output resolution is held fixed, across kernel sizes
  1x1/3x3/5x5.

## Scaling-law checks (already covered by existing per-module suites)

- `test_timing.py`: doubling clock halves compute time; doubling
  bandwidth halves memory time; schedule choice changes memory time but
  not compute time; PE-array choice changes compute time but not
  schedule-derived DRAM traffic.
- `test_transformer.py`: doubling sequence length doubles projection/MLP
  FLOPs and quadruples attention FLOPs (`test_sequence_length_scaling_quadratic_attention_linear_projection`).
- `test_explore.py` / `test_transformer.py` / `test_convolution.py`:
  deterministic ranking verified by running identical searches twice and
  comparing candidate order.

## Regression contracts preserved

- `4x4x4 FP32, tile 2x2x2`: c-resident=320B, a-resident=384B,
  b-resident=384B (unchanged since Milestone 5).
- Tiny Transformer block (`B=1,S=2,D=4,H=2,F=8`) = 576 modeled GEMM FLOPs
  (unchanged since Milestone 8).
- 1x1 Conv2D expansion ratio = 1.0; 3x3 example expansion ratio = 3.24
  (unchanged since Milestone 9).

## Determinism

`tests/test_experiments.py` verifies that running the same
`ExperimentSpec` twice produces byte-identical `to_json()` output, for
all four workload kinds (gemm/transformer/conv2d/cnn) and confirms the
JSON result contains no wall-clock timestamp or other non-deterministic
field.
